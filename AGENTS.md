# Instruções para agentes

## Validação

Ao implementar ou corrigir comportamento, revisar um PR ou preparar sua conclusão,
leia e execute [o workflow de validação](docs/workflow-validacao.md). Ele define
os testes, as verificações de navegador por superfície e o recibo de evidências.
Execute as etapas aplicáveis no ambiente acessível; uma etapa bloqueada exige
tentativa e motivo concreto no recibo, em vez de uma pendência genérica.

Consulte [DEVELOPER.md](DEVELOPER.md) para configuração e
[ARCHITECTURE.md](ARCHITECTURE.md) para os limites da extensão. Preserve a
implementação sem dependências npm e os dados reais fora do Git.
